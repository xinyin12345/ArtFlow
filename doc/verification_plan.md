# v06 验证计划

目标：证明新增显示逻辑、按键、遥测以及与既有视频链的集成；分别记录 RTL 仿真、固件测试、FPGA 实现、实板验收。沿用 v05 原生 Questa/SystemVerilog 自检环境，不另引入 UVM/VCS 依赖。

| 优先级/功能 | 激励与检查 | 证据 |
|---|---|---|
| P0 OSD | 9 帧，四模式，OSD 开/关，首次无统计；1728000 像素逐个 Python 参考比较，所有同步周期检查 | tb_v06_osd + pixel_reference |
| P0 按键 | 短毛刺、稳定按下、短释放反弹、长按、循环回绕、OSD 开关、复位 | tb_v06_ui |
| P0 FPS | 非整数周期事件、空窗口、窗口边界、>999 饱和、BCD 进位、复位；独立事件模型 | tb_v06_fps |
| P0 帧原子性 | 全 1080p 画面中途改变按键；模式/OSD/数字只允许正 VS 更新 | tb_v06_chain |
| P0 Gamma/OSD 串联 | 4 个 1920×1080 帧，LUT 后的 RGB、左右遮罩、色条和所有同步周期；OSD 区域由单测检查 | tb_v06_chain |
| P0 原视频/控制保留 | AXI 错误、拥塞、断流、三缓冲、逐像素、Bayer、camera gate、APB 多时钟 | run_v06 --full 调用继承回归 |
| P0 板卡可实现 | 固件重建、引脚无冲突、源快照、综合、布局布线、bit/hex、正常 setup/hold、继承 CDC | run_efinity.ps1 |
| P1 固件不变 | C 主机 5 组、生产 bin 与 v05 一致 | test_firmware + SHA256 |
| P1 实际运行 | 真实按键/HDMI/FPS、停止相机、30 分钟持续显示 | board_acceptance，必须实板填写 |

正向仿真必须退出成功、存在明确 PASS、零 Error/Fatal/Warning；像素检查必须完整消费预期帧及所有像素。回归开始写 RUNNING，结束检查源哈希，缺日志或旧源码不得签核。预期失败门禁只在匹配明确故障信息时通过。

不把工具可执行、静态检查或旧版报告当作仿真完成；不把仿真帧数换算为实板运行时长。不宣称未采集的行/分支/翻转覆盖率。FPGA 实现警告按实际记录保留，不能标注全工程零警告。
