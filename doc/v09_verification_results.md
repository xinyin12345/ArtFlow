# v09 S8 候选验证结果（2026-10-12）

结论：可以交付完整 S8 风格网络的上板效果候选镜像；**不满足原计划 v09 ≥15 fps 的验收目标，也未完成动态 APB 权重加载和板级验收**。初次验证时未提交，基线提交为 `6edf0f0`；2026-10-12 按用户要求纳入 v09 候选版本提交，验证边界不变。

## 工具限制与未验收项

- Icarus Verilog 13.0 在当前环境存在“代码生成完成后进程异常退出”的问题。脚本要求全新 VVP、编译日志无错误、VVP 正常退出、scoreboard 完成，汇总标为 `PASS_WITH_TOOL_LIMITATIONS`，没有把编译器异常记为正常通过。
- Questa 启动出现 WinError 623，当前真实 Sapphire CPU/PLIC 仿真为 `TOOL_BLOCKED`。原厂加密核未替换；固件主机测试、APB 驱动系统测试和综合连线不代替真实 CPU 联调。
- 当前没有 UVM、代码覆盖率或功能覆盖率数据库；报告中的测试数量和比较数量不是覆盖率百分比。
- 板级风格画质、CAP/PRC 实测、长时间稳定性、真实 IRQ、固定图注入及 DDR 读回校验和待用户上板确认。
- 使用冻结 ROM 权重，没有实现 RISC-V/APB 权重装载；没有新增原计划的 CI/CO/并行度通用 INT32 单层或 8→8/24-MAC 独立微基准。
- ≥15 fps 需要后续架构/调度/时钟与 DDR 优化。本次保持板级时钟和接口配置，先交付完整网络效果。
