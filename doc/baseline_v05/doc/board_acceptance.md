# v05 实板验收记录模板

当前状态：**NOT_RUN**。本次开发尚未烧录板卡、采集真实 UART 或观察 HDMI；仿真及 bitstream 生成不能代替本页验收。v04 的 30 分钟实板项目同样尚未签收。

1. 在 Ti60F225 DemoBoard v4 上连接 SC431HAI、HDMI 与板载 USB 串口，确认板卡/传感器型号和电源。记录板号、摄像头、显示器和线缆。
2. 记录本次 `ArtFlow_v05.bit`/`.hex` SHA-256，使用 Efinity Programmer 下载。程序已在 BRAM 初始化中，无需另烧录软件 SPI 镜像。
3. 串口设置 115200 8N1、无流控；系统复位后保留从 `ArtFlow v05 Sapphire RV32IM` 到 `READY; type help` 的完整日志。摄像头应报告 `OK camera 164 registers verified 1920x1080`。
4. 观察上电色条后切入左右双窗口。DDR 校准完成后 LED0 闪烁；LED2 表示 camera_ready，LED3 表示 camera_reset（LED 电气亮灭极性由板卡决定）。
5. `status` 应读到默认 active=`280 255 350`。依次发送 `wb 256 256 256`、`wb 512 256 256`、`defaults`；每次必须收到 `OK wb applied`，图像和两个窗口同步变化，无帧内变色横线。保存串口与图像证据。
6. 输入 `wb 1025 256 256`、负数、非数字、缺参和过长行，确认被拒绝且 active 不变。停止相机后观察 commit 是否在安全边界等待，不把 `PENDING` 当成功。
7. `cam off` 后查询状态，再 `cam init`，确认重新读回和显示恢复。验证摄像头未连接时的 NACK/TIMEOUT、CLI 响应和重新连接后的人工重试；连接操作须遵守板卡供电要求。
8. 动态场景连续运行至少 1800 秒，多次调增益，记录无撕裂、无显示断流、无异常复位的起止时间与视频。完成断电重启和外部系统复位检查。
