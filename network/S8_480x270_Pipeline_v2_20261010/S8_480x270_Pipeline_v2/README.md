## 接口约定

- `start` 在空闲时启动；`busy` 运算期间为高；`done` 完成脉冲；`frame_cycles` 表示当前/最近一帧的核心周期。
- DDR 逻辑口 64 位，24 位字节地址，8 字节对齐；ready 接受读或写命令。读响应至少下一周期返回，最多一个读未返回；写命令以 ready 接受为完成。此口尚不是物理 DDR 控制器或 AXI 突发接口。
- 命令在背压期间保持稳定。需要系统适配器保证读响应不丢失、不重排，并正确处理跨时钟和复位。
- 三个 2 MiB 区域位于 `0x000000`、`0x200000`、`0x400000`。开始前将输入 NHWC 写入第一块；每像素 8 字节，RGB 放低三字节，其余补零。输出同样位于第一块，共 480×270 个像素。
- 中间特征每个通道暂存 1 字节，通道数补齐到 8 的倍数；U4 仍使用字节存储。S8 按二补码。
- 先前图像的输入区不能在 CNN 读取期间被采集端覆盖。显示端不能读取仍被写入的输出区；系统需要独立采集/显示缓冲及帧所有权切换。
- 默认 EXT_W=480、EXT_H=270。其他尺寸必须满足本工程验证脚本和行缓存地址范围要求，参数变化后需重新生成/综合和验证。

这是 CNN 独立核交付。没有摄像头/HDMI、DDR 控制器、板级引脚或 PLL 配置；不能直接作为完整视频系统下载文件。
